# fair-brook-lite



拿来练手的小仓库

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/fair-brook-lite.git
cd fair-brook-lite
chmod +x run.sh
```
